# PTIT Found

Ứng dụng tìm đồ thất lạc trong trường PTIT, xây dựng bằng Next.js App Router và TypeScript.

## Chạy ứng dụng

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000).

## Kiểm tra

```bash
npm test
npm run lint
npm run build
npm start
```
